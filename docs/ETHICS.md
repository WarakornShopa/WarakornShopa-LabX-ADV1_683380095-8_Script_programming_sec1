
# Web Scraping Ethics

## 1. Respect the Website
Use web scraping only for learning and educational purposes.

## 2. Request Rate
Add a delay between page requests to avoid sending requests too frequently.

## 3. Public Information
Collect only publicly accessible information needed for this project.

## 4. Website Policies
Check the website's terms of service and robots.txt before scraping.

## 5. Data Privacy
Do not collect personal or sensitive information.

## 6. Responsible Use
Do not overload the website or use scraped data for harmful purposes.

## 7. Project Scope
This project scrapes book information from Books to Scrape for educational practice.
